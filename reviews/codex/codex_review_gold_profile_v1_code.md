## Claims From `dfaf206`

- "Profile plots counted RAW rate, PRU gold-down = 91% on both" - verified true on the live GDX page; GDXJ also verified at 93%.
- "Slope wording gated on an actually-drawn line" - partially true, but overstates the guard. It checks any adjacent segment, not whether the segment supports a down-vs-up interpretation.
- "Usable down/up coverage counts moved out of the renderer into the loader - no counting in serve" - overstates. The counts moved out of the renderer but remain in `serve/lab_curve_data.py`.
- "Aria-label now names the real benchmark/horizon/ticker + coverage" - verified true for GDXJ.
- "DOWN_BUCKETS/UP_BUCKETS + BUCKET_SHORT_LABELS now live once... derived from bucket bounds" - DOWN/UP are derived from bounds; short labels are centralized but manual.
- "dial_cells is read once per drill-down request" - true for the happy path, but the cells read status is ignored.
