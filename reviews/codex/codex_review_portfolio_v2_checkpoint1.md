# Codex Review - Portfolio Schema v2 Checkpoint 1, Increments 3-4

Verdict: **NEEDS CHANGES before Checkpoint 2**

The direction is right: cost-currency FX is resolved in the backend, GBP presentation is computed in `portfolio/pipeline.py`, local P&L is suppressed for mixed cost/quote currency rows, v6 artifacts are manifest-read through the existing stale-schema path, and the focused tests pass. I found two money-critical gaps that matter before Snowball rows arrive: local same-currency P&L still depends on the legacy `buy_price` leg, and aggregate P&L can be computed from partial costs when one lot is missing cost FX.

Tests run: `python -m pytest tests/test_portfolio_valuation_v2.py tests/test_portfolio_artifacts_v6.py tests/test_fx_histories_split.py -q` -> **13 passed**.
