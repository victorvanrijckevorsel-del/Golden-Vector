## Bottom Line

The backend spine is directionally solid: compute once, persist, shared math, no serve arithmetic, peer ranks are benchmark-independent, and most abstention mechanics are conservative.

The risky part is user-facing confidence. Current artifacts can emit hard labels that are either horizon-misaligned, anchor-disagreed, not multiplicity-corrected enough, or semantically stronger than the test proves. Fix those before UI work, because once the UI reads these fields it will be easy to accidentally present exploratory labels as settled facts.
