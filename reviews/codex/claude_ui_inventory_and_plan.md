## Tool A — Gold Sensitivity (structural overview)
_Proposed intro:_ Gold Sensitivity: this table ranks every miner by how strongly and how reliably its share price tracks the gold price; lower rank is better, and you can click any column heading to see what the number means and how it's calculated.
_Top win:_ Replace the hover-only tooltip with a click-to-open explanation panel and wire EVERY Tool A header into it — including the currently unexplained Profile and Rank columns and adding the missing score formula — so the page's most-read labels (Profile, Score, Rank) finally show meaning + formula + Read-more on click instead of a transient hover box that is invisible on mobile.

### Metric -> formula dictionary (content for the click-to-explain panels)
| Column | Formula | Plain-English | Explained today |
|---|---|---|---|
| Profile | none (label) — decision tree on the core delta/gamma/asymmetry/up-down betas: SCORE_WITHHELD / UNRELIABLE_SIGNAL / LOW_LINKAGE / FRAGILE (down_beta>up_beta & delta>0.75) / CONVEX (gamma<=-0.15 & asymmetry>=1.1 & delta>=1.5) / HIGH_DELTA (delta>=2.0) / LINEAR / DEFENSIVE | A one-word bucket summarizing the stock's gold behavior (e.g. high-leverage, convex, fragile, defensive). | none |
| Δ Core | structural_delta_core = weighted_median over {6M,12M,3Y} of beta, where beta = slope of OLS regression of weekly stock log-returns on weekly gold log-returns = sum((x-x_mean)(y-y_mean)) / sum((x-x_mean)^2) | How much the stock tends to move for each 1% move in gold (its gold beta), blended across the 6-month, 1-year and 3-year windows. | hover_tooltip |
| Gamma | structural_gamma_core = weighted_median over windows of gamma_value, where gamma_value = down_beta - up_beta (down-week gold beta minus up-week gold beta) | How differently the stock reacts when gold falls versus when it rises; negative is favorable (more up-capture than down-exposure). | hover_tooltip |
| Asymmetry | asymmetry_ratio_core = weighted_median over windows of asymmetry_ratio, where asymmetry_ratio = up_beta / down_beta (only when \|down_beta\| >= 1e-9) | The ratio of up-gold sensitivity to down-gold sensitivity; above 1 means it captures more upside than downside. | hover_tooltip |
| Confidence | confidence_label from confidence_score thresholds (HIGH>=0.8, MEDIUM>0.45, else LOW; WITHHELD on bad normalization). confidence_score = 0.25*coverage + 0.30*fit + 0.20*sign_consistency + 0.15*delta_stability + 0.10*regime_readiness, where fit = clamp(0.6*mean_R2 + 0.4*min_R2) | How trustworthy the sensitivity estimate is, based on history depth, regression fit, and stability; low-confidence names are held out of the ranking. | hover_tooltip |
| Volatility | volatility_context label from 52-week annualized vols: HIGH_DOWNSIDE_RISK if downside_vol>=0.5; HIGH_NOISE if residual_vol>=0.6 or total_vol>=0.75; LOW_NOISE if residual_vol<=0.35; else MODERATE_NOISE. Each vol = std(weekly log returns, ddof=1) * sqrt(52) | How noisy the stock is around its gold relationship (total, stock-specific/residual, and downside swings). | hover_tooltip |
| Gold Sensitivity Score | tool_a_score = 100 * (0.40*delta_component + 0.25*gamma_component + 0.15*asymmetry_component + 0.20*confidence_score), each component clamped to [0,1]; null unless score_eligible | The overall 0-100 gold-sensitivity score that sets the page ranking, weighting delta, gamma, asymmetry and confidence. | hover_tooltip |
| Rank | tool_a_rank = dense rank of tool_a_score (descending) within each as_of_date, over score-eligible rows only; ineligible rows are NA and sort last | Position in the universe by score; 1 is the strongest gold play, blank means held out of the ranking. | none |
| Notes | none (raw count) — number of saved stock notes for the ticker | How many notes you've saved on this ticker. | none |
| Ticker | none (raw/label) | The stock symbol, linking to its full structural breakdown. | none |

## Tool B - Corporate Finance (forward alpha / valuation), route /tool-b
_Proposed intro:_ Industry-standard corporate-finance health checks for each gold miner at a chosen gold price: how many quality checks it passes (the rank), plus standard valuation and cost ratios (EV/EBITDA, Forward P/E, FCF yield, AISC, Net Debt/EBITDA) - move the gold dial to re-price and re-rank the whole table live.
_Top win:_ Make the column headers actually explanatory: add click-to-open help panels that include the FORMULA for every calculated column (Forward EBITDA, Forward P/E, FCF Yield, EV/EBITDA, Score) AND add explanations to the eleven currently-bare columns (especially Rank and Verdict, whose rules are non-obvious) - today 11/20 columns have zero explanation, the calculated ones that do have help omit their formula, and hover-only tooltips are unreachable on touch.

## Evidence Scorecard (/scorecard)
_Proposed intro:_ "Did each ranking actually work? Each card is one tested claim: a plain SUPPORTED/NOT SUPPORTED verdict on top, the evidence stats below — click any stat to see what it means and how it's computed."
_Top win:_ Make the evidence stat line click-to-explain: wrap IC, t, '% of periods', tercile spread, and the verdict badge each in a click panel that gives the plain-English meaning, the actual formula from validation.py (Spearman rank correlation; Newey-West lag-1 t-stat; top-third-minus-bottom-third spread; the all-gates-pass verdict logic) and a Read more. Today these — the most technical and load-bearing numbers in the whole workspace — have zero explanation, while only the secondary autocorr/ceiling diagnostics get a tooltip.

### Metric -> formula dictionary (content for the click-to-explain panels)
| Column | Formula | Plain-English | Explained today |
|---|---|---|---|
| verdict (e.g. SUPPORTED (exploratory - survivor-only universe) / NOT SUPPORTED / INCONCLUSIVE / PARTIAL / ACCRUING) | SUPPORTED if all gate_results True; INCONCLUSIVE if median_ceiling < 0.30; NOT SUPPORTED if 0 gates pass; else PARTIAL. (golden_vector/lab/validation.py:307-320 _classify) | The headline pass/fail of the historical test: SUPPORTED means every pre-locked bar was cleared on out-of-sample, walk-forward data in today's surviving-name universe. | inline_text |
| claim (e.g. 'Tool A Δ Core gearing ranking is stable out of sample') | none (raw/label) | Plain-English statement of exactly which ranking was tested and what it should predict. | none |
| N test periods (rendered as 'N test periods') | n_folds = count of walk-forward folds whose cross-section had enough names (>= MIN_CROSS_SECTION) to score (validation.py run_e1b/e2 loops; scorecard.py:116) | How many independent historical time-slices the ranking was tested across; more periods means a more trustworthy verdict. | none |
| IC (Information Coefficient, 'IC {value}') | mean_ic = average over folds of Spearman rank correlation between the predicted rank and the realized forward outcome; spearman_ic = corr of average-rank(pred), average-rank(outcome). (validation.py:94-107, 518-519, 572) | On average, how well the ranking's order matched the order of what actually happened next (rank correlation; 0 = no relationship, 1 = perfect). | none |
| t (Newey-West t-stat, 't {value}') | nw_t = mean(fold ICs) / sqrt(LRV / n), where LRV = gamma0 + 2*(1/2)*gamma1 (Bartlett lag-1 HAC variance), gamma0=sum(resid^2)/n, gamma1=sum(resid_t*resid_{t-1})/n. (validation.py:110-134, 573) | How confidently the average IC is above zero rather than luck, after adjusting for the fact that adjacent test windows overlap; gate is t > 3.0. | none |

| spread (tercile spread, 'spread {mean} (t {t})') | tercile_spread per fold = mean(outcome of top third by rank) - mean(outcome of bottom third); mean across folds = tercile_spread_mean; tercile_spread_t = Newey-West t of those per-fold spreads. (validation.py:326-352, 575-576) | How much better the top-ranked third of names actually performed than the bottom third, on average, with a t-stat for whether that gap is reliable. | none |
| diagnostics popover: Fold-IC autocorrelation | fold_ic_autocorr = sum(c[1:]*c[:-1]) / sum(c^2), where c = fold ICs minus their mean (lag-1 autocorrelation). (golden_vector/lab/scorecard.py:104-113) | How much each period's result echoes the previous one; high values mean the test periods are less independent than their count suggests. | hover_tooltip |
| diagnostics popover: outcome split-half consistency (ceiling) | median_ceiling = median over folds of Spearman(odd-week outcome rank, even-week outcome rank); per fold the forward window is split odd/even weeks and the two halves are correlated. (validation.py:520-523, 577) | A noise ceiling: how repeatable the per-name outcome itself is when you split the weeks in half — low values mean the outcome is noisy so only a cross-period verdict is trustworthy. | hover_tooltip |
| baseline lines (e.g. 'does not beat the single-window beta baseline') | Emitted when paired Newey-West t of (core IC - baseline IC) is NOT > 2.0 across folds. (validation.py:561-567) | A plain caveat shown only when the ranking failed to reliably beat a simpler benchmark ranking. | none |
